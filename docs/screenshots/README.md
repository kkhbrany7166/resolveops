# ResolveOps Screenshot Checklist

Add the following screenshots manually before sharing the public repository with recruiters or hiring managers.

## Required Screenshots

1. `dashboard.png`
   - Full ResolveOps dashboard.
   - Live metric cards visible.
   - Active requests table visible.

2. `ai-request-analysis.png`
   - New Request modal after AI analysis completes.
   - Show generated title, category, priority, and location fields.
   - Do not expose API keys or terminal windows.

3. `request-management.png`
   - Request Management modal.
   - Show technician assignment and status controls.
   - Prefer a request assigned to Ali, Khalid, or Ahmed.

4. `operations-copilot.png`
   - Operations Copilot modal with one grounded answer.
   - Recommended prompt: "What needs my attention right now?"
   - Include referenced request chips and recommendations when available.

## Naming

Keep filenames lowercase and match the names above exactly:

```text
docs/screenshots/dashboard.png
docs/screenshots/ai-request-analysis.png
docs/screenshots/request-management.png
docs/screenshots/operations-copilot.png
```

After the files exist, add image links to the root `README.md`.
